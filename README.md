# Projeto Nuxt - Cadastro

Aplicação desenvolvida para a atividade prática de Node.js, Vue.js e Nuxt.

## Tecnologias

- Node.js
- npm
- Vue.js 3
- Nuxt
- TypeScript
- HTML
- CSS

## Funcionalidades

- Página inicial
- Menu de navegação
- Roteamento com Nuxt
- Página de cadastro
- Validação de nome
- Validação de e-mail
- Seleção de curso
- Seleção de semestre
- Checkboxes de interesses
- Bio com limite de 300 caracteres
- Contador de caracteres
- Feedback de erro
- Feedback de sucesso
- Limpeza reativa do formulário
- Layout responsivo
